# Playtest checklist: one walk through a full run

One ordered walk through a full run, consolidated from every work package's manual checks of the 2026-10 overhaul. Items marked **(new)** changed in WP12 part 3; **(fix 1)** and **(fix 2)** are WP12's review fix rounds (their two amendment lists, merged here by the final fix pass); **(final fix)** is the final fix pass.

**Setup.** Chrome at 1440×900, headphones. Play at http://localhost:5173/; add `?debug` only where an item says so (it adds a warp ladder to the header and `__ap` to the console). To start as a first-time player: with `?debug`, run `__ap.archiveClear()` and reload (an archive written by a pre-WP8-fix build reads ARCHIVE CORRUPT once: press WIPE ARCHIVE). Play one whole run by the strip first, then go back for the "try this" items.

**Run 1, ship 1: ARES-VII (the tutorial).**
